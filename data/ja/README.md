# data/ja/ 说明

日文专用的词库目录，与英文的 `data/` 完全隔离 —— 日语不加载英文的
`pos.json` / `base.txt` / `lemmatize.exceptions.json`，也不需要 ECDICT。

| 文件 | 作用 | 填错的后果 |
| --- | --- | --- |
| `stopword.txt` | 助词、助动词、记号等「不学的词」，一行一个 | 虚词混进正文（噪声） |
| `known.txt` | 你已掌握的日文词，不重复出；一行一个**原形**（如 `食べる`） | 想看的词不出现 |

补充说明：

- 日文没有空格，所以最小词长默认是 1，`猫`、`手` 这类单字实词会保留。
- 分词用 kuromoji（IPADIC 词典），它能给原形、读音、词性 —— 但它**不是日汉词典**，
  不提供任何中文释义。释义请通过界面里的用户词表补充。
- 词典里查不到的词会被标记为「未知词」（`unknown: true`），保留表面形和原句，
  读音留空，不会编造。
- 读音以**平假名**存储和展示。
